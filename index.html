A little company beside your work. Your pet’s poses reflect activity in supported ChatGPT and Codex interfaces, from getting on with a task to waiting for your input.

Bring a pet into ChatGPT + Codex ↗
Install in ChatGPT desktop or Codex＋
  1. Unzip your teammate. Keep the named pet folder and its files together.
  2. Add it to your pet folder. Copy that folder into ~/.codex/pets/. Back up an existing folder with the same name before replacing it.
  3. Choose your companion. In ChatGPT desktop, open Settings → Pets → Refresh and select the dog. In an interactive Codex terminal, type /pets.

Use a supported desktop app or image-capable terminal. ChatGPT web has a separate upload format; these downloads are desktop/CLI packages. Official setup and availability guide ↗

Ask your teammate to bowl an over of up to six useful items, catch defects in a review, or show the scorecard. The playbook works through Codex requests and keeps your score locally between invocations.

Download the Codex task skill ↓

Install the task playbook＋
  1. Unzip the skill. Keep the brian-cricket folder and its files together.
  2. Add it to Codex. Copy the folder into $CODEX_HOME/skills, or ~/.codex/skills if CODEX_HOME is unset. Preserve an existing version before replacing it.
  3. Make a cricket call. Use $brian-cricket in your next Codex turn. Reopen Codex if needed. The included README covers first-use scoring; Node.js is required.

Pet appearance and the task skill are separate installations. This optional Codex skill does not control pet frames, monitor other chats or install a ChatGPT task integration. The download contains no personal score or history.

An optional cricket companion

Bring match day
to your teammate.

Look up cricket with ESPNcricinfo source links.
Add an API feed with your own Sportradar access.

Ask your dog about a match, player or scorecard. Match Day keeps real cricket scores separate from the runs you earn for completed work.

Download Match Day ↓

Choose your Match Day setup＋
  1. Install the optional skill. Unzip and copy cricket-matchday into your Codex skills folder. Preserve any existing version. Follow the included README.
  2. Start with sources. Use $cricket-matchday to research a match or player through ESPNcricinfo source links. This mode uses web research, with no bundled ESPN API.
  3. Add an API if you have access. The separate Sportradar adapter requires your own API key, cricket coverage and explicit activation. It starts disabled. API behavior has been tested with synthetic fixtures; live access is unverified.

Node.js is required for the adapter. Installing a pet does not enable Match Day, connect it to a live match or make its animations follow scores.

Bring a teammate into WhatsApp＋
  1. Download and unpack. Save the sticker ZIP, then open it to extract the individual image files.
  2. Keep your favourites. Save the images you want to your device’s photos or files.
  3. Create your sticker. Open a chat in WhatsApp and use its Create sticker option. Choose a saved image, adjust it, then save or send it.

The ZIP is a collection of images; downloading it does not automatically install a WhatsApp sticker pack. WhatsApp’s sticker guide ↗
